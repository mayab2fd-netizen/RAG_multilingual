# 📄 PDF 다국어 질의응답 & 번역기 (RAG)

Streamlit과 Langchain을 활용하여 만든 PDF 기반 다국어 질의응답 웹 애플리케이션입니다. 사용자가 올린 문서를 분석하고, 원하는 언어로 맞춤형 답변을 제공합니다.

## ✨ 주요 기능
- **문서 분석 (PDF)**: 빠르고 정확하게 PDF의 텍스트를 추출하여 지식 기반(Vector DB)을 구축합니다.
- **다국어 지원**: 질문과 상관없이, 선택한 언어(한국어, 영어, 일본어, 중국어 등)로 답변을 강제하여 번역 수고를 덜어줍니다.
- **RAG (검색 증강 생성)**: FAISS 벡터 데이터베이스를 통해 문서 내에서 가장 정확한 근거를 찾아 답변을 생성합니다.
- **멀티유저 안정성**: Streamlit 환경에서 다수의 유저가 동시에 접속해도 API Key가 충돌하지 않도록 안전하게 설계되었습니다.

## 🚀 로컬 실행 방법

### 1. 패키지 설치
이 프로젝트를 로컬에서 실행하려면 필요한 라이브러리를 설치해야 합니다. 터미널(또는 명령 프롬프트)에서 아래 명령어를 입력하세요.
```bash
pip install -r requirements.txt
```

### 2. 애플리케이션 실행
설치가 완료되면, 아래 명령어로 웹 페이지를 띄울 수 있습니다.
```bash
streamlit run app.py
```

## ⚙️ 사용 방법
1. 앱이 실행되면 좌측 사이드바에 **OpenAI API Key**를 입력합니다.
2. 분석하고 싶은 **PDF 파일**을 업로드합니다.
3. **'문서 분석하기'** 버튼을 누릅니다.
4. 분석이 완료되면 우측 메인 채팅창에 질문을 자유롭게 입력합니다!

## 🛠 사용된 기술 스택
- **Frontend / UI**: Streamlit
- **PDF Parsing**: PyMuPDF (`fitz`)
- **LLM & AI**: Langchain, OpenAI (`gpt-4o`, `text-embedding-3-large`)
- **Vector DB**: FAISS (`faiss-cpu`)
