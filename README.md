# ⚖️ AI 글로벌 계약서 & 법률 문서 분석기

해외 거래 계약서, 영문 법률 문서를 업로드하면 AI가 핵심 조항을 찾아 원하는 언어로 분석·번역해주는 웹 서비스입니다.

## ✨ 주요 기능
- **계약서 조항 분석**: 위약금, 해지 조건, 책임 범위 등 핵심 조항을 빠르게 찾아 요약합니다.
- **다국어 번역 답변**: 영문/중문/일문 등 다국어 계약서를 업로드하고, 한국어로 질문하면 한국어로 답변합니다. 6개 언어를 지원합니다.
- **법률 용어 원문 병기**: 중요한 법률·계약 용어는 원문(영어 등)을 괄호 안에 함께 표시하여, 번역의 정확성을 보장합니다.
- **RAG 기반 정확한 답변**: FAISS 벡터 검색으로 문서 내에서 가장 관련 있는 조항을 찾아 근거 기반 답변을 생성합니다.
- **멀티유저 안정성**: 여러 사용자가 동시에 접속해도 API Key가 충돌하지 않도록 안전하게 설계되었습니다.

## 🎯 이런 분들께 추천합니다
- 해외 파트너와 영문 계약서를 주고받는 **무역·수출 기업 담당자**
- 외국어 약관이나 NDA를 빠르게 검토해야 하는 **스타트업 대표·프리랜서**
- 해외 법률 문서를 다루는 **법무팀·기획팀 실무자**

## 🚀 로컬 실행 방법

### 1. 패키지 설치
```bash
pip install -r requirements.txt
```

### 2. 애플리케이션 실행
```bash
streamlit run app.py
```

## ⚙️ 사용 방법
1. 앱이 실행되면 좌측 사이드바에 **OpenAI API Key**를 입력합니다.
2. 분석할 **계약서 PDF 파일**을 업로드합니다.
3. **'문서 분석하기'** 버튼을 누릅니다.
4. 분석이 완료되면 채팅창에 자유롭게 질문합니다!
   - 예: "지각 시 위약금 조항이 어떻게 돼?"
   - 예: "계약 해지 조건은 뭐야?"
   - 예: "책임 제한(Limitation of Liability) 조항을 요약해줘"
